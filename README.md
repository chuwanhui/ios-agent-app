# 手机智能体 · Scripting

一个跑在 iPhone 上的**真·智能体**：打字 → DeepSeek 大模型 → 调用手机上的真实能力 → 回答。
基于 [Scripting](https://scripting.fun)（iOS 上的 TypeScript 脚本运行器），**无第三方 npm 依赖**。

```
输入 → DeepSeek（带上下文 + function calling）→ 工具（快捷指令 / MCP / 知识库 / 技能）→ 回复
```

## 功能

| 模块 | 说明 |
| --- | --- |
| **聊天页** | 参考 DeepSeek / ChatGPT 的布局：角色形象、多会话、左侧隐藏抽屉放历史 |
| **流式输出** | 回复逐字打出（打字机），思考过程边想边滚，每轮显示 token 用量（`↑ 输入 · ↓ 输出`）|
| **多家供应商・多个 Key** | 模型配置支持同时存好几家（每家一套 接口地址 / API Key / 请求路径 / 模型 / 余额），聊天只用「当前使用」那一家；同一家配多个 Key、或一个 Key 换不同的中转地址，当两家分开加。老配置（只有一套地址 + Key）打开时自动搬成第一家，不用重填 |
| **模型从接口拉** | 模型名不给手输：在「模型配置 → 模型 → 某家供应商」里填好地址 + Key，**一进这一页就自动拉一次** `/models`，把服务端真正支持的模型列出来再选；也能随时点「重新拉取」。同一家还会自动查一次余额（按服务商自己的余额端点，见「已知限制」）。列表和余额都跟设置一起保存，下次打开还在 |
| **自定义头像** | 设置页从相册选照片，自动方形裁剪 + 缩到 512pt；没照片（或文件被系统清掉）时显示**灰色圆形占位图**，不再用 emoji |
| **性格与角色** | 提示词只有这一处：设置 → 角色与外观 → **性格与角色**。身份、说话方式、什么时候该调工具全写在这一段里，支持编辑 / 预览 / 恢复默认 / 清空，改完下一轮就生效。代码里不掺任何额外的「系统提示词」，只剩新装用户的出厂种子（`core/agent/prompts.ts`），日常调人设不用碰代码 |
| **快捷指令工具** | 一个真实快捷指令 = 一个工具；在「工具」子页里直接填名字（也能粘「快捷指令」里拷来的名字）× 参数行 × 说明，全程表单、不用写 JSON；还能让快捷指令末尾的**回调 URL 把结果传回来**。工具一多先在顶部按名字搜，点进去才是配置 |
| **MCP 工具** | 远程 MCP 服务器（Streamable HTTP），带**返回值**的 JSON-RPC 工具 |
| **知识库** | 纯本机离线全文检索（中文 bigram + BM25，纯 JS）；支持 txt / md / json / csv / log / pdf |
| **技能（skill）** | 上传含 `SKILL.md` 的文件夹或 zip，或直接从 Git 仓库（GitHub / GitLab，可指向子目录）安装；渐进式披露 + `read_skill` 按需读取 |
| **文件导入** | 知识库 / 技能页用系统「文件」选择器直接上传（支持多选），不必先拷进收件箱 |
| **挂载外部文件夹** | 知识库可用安全作用域书签挂一个外部目录（如 Obsidian 库），只读索引、原文件不动，之后点「更新索引」增量同步 |
| **MCP 批量导入** | 粘贴 MCP 客户端的 `mcpServers` JSON（Claude Desktop / VS Code / Cursor 等格式）一次导入多台服务器；stdio 型会明确拒绝 |
| **统一配置** | 聊天按设置里的默认配置执行：模型、思考档位、记忆条数、知识库、技能、工具与 MCP 都统一在设置里管，聊天页不再单独挑能力 |
| **能力开关** | 智能体「自己动手」的权限，**默认全关**：读写文件 / 执行命令行 / 运行技能里的脚本 / 自己创建技能 / 自己配置快捷指令工具；文件类能力锁在本 App 目录内（默认工作区 `Scripting/工作区`）|
| **产出文件** | 智能体写出的文件以卡片挂在回复下方，点一下用系统菜单存到「文件」或分享 |
| **改完即存** | 设置里所有页面都是**改一下就存盘**，没有额外的「保存」按钮；技能启停 / 删除、知识库导入 / 清空也一样 |
| **消息记录** | 底部「记录」标签按 App → 联系人分组，看收到什么、回了什么、什么时候；页面底部有「怎么接微信 / 钉钉」的完整说明（通知 JSON 协议 + 快捷指令配置 + 去重 / 重试规则，Markdown 渲染，可一键拷贝模板）|
| **快捷指令 App 集成** | 两个入口：①「打开 URL」→ `scripting://run/智能体?message=<URL 编码文本>`，App 被拉到前台跑一轮（推荐，AI 能正常触发快捷指令工具）；传通知 JSON 时按「App + 发件人」锁定一条会话，App 直接跳到那条会话；②「运行脚本」→ `intent.tsx`，后台跑、结果直接作为返回值（后台拉不起别的 App，所以调不动快捷指令工具）|
| **桌面启动器** | 主屏小部件（`widget.tsx`）：头像 + 名字 + 最近会话，点一下把 Scripting 拉到前台打开聊天页 |

## 安装

1. 在 iPhone 上安装 **Scripting**，把本仓库放到 `<AppGroup>/Documents/scripts/` 下（目录名 `智能体`）。
2. 打开脚本 → 底部**设置** → 「模型配置」→「模型」→ 填个名字（如 DeepSeek）+ **接口地址** + **API Key**；模型列表会自动拉回来（进这一页时脚本会请求一次 `/models`），从列表里选一个（**模型不给手输**）。想加第二家（别的厂商 / 另一个 Key / 一个中转地址）就再点「＋ 添加供应商」，然后在详情里点「设为当前使用」切着用。
3. 可选：
   - 设置 → 角色与外观：改助手名字、换头像，写**性格与角色**——它就是发给模型的全部设定（可随时恢复默认）
   - 设置 → 模型配置 → 行为与思考 / 对话 / 图片输入：思考深度、记忆条数、图片压缩
   - 设置 → 能力权限：知识库检索、技能、以及智能体读写文件 / 跑命令行等权限（**默认全关**）
   - 底部「能力」→ 知识库：点「导入」选文件（可多选），或挂一个外部文件夹；也可以把资料丢进「文件」App 的 `Scripting/知识库` 再点「扫描并导入」
   - 底部「能力」→ 技能：上传含 `SKILL.md` 的 zip / md，或填 `owner/repo`（仓库 URL 也行）从 Git 仓库安装
   - 底部「能力」→ 快捷指令：点「＋ 添加一条工具」，快捷指令名手输或粘「快捷指令」里拷来的名字（要和 App 里完全一致），参数点「＋ 添加参数」一行一个
4. 在「快捷指令」App 里接上本脚本，两种接法：
   - **「打开 URL」**，内容 `scripting://run/智能体?message=<URL 编码后的文本>` —— 推荐，App 到前台，AI 能正常调快捷指令工具（Siri / 微信 / 钉钉转发都走这条）；
   - **「运行脚本」**，把文本当输入 —— 后台跑，结果直接当返回值，但后台开不了别的 App，调不动快捷指令工具。

## 快捷指令工具：协议

一个真·快捷指令 = 一个工具。底部「能力」→ 快捷指令：

- 点「＋ 添加一条工具」加一行，**快捷指令名**手输（也可以先在「快捷指令」里拷名字，回来点「粘贴剪贴板里的名字」）—— 要和「快捷指令」App 里**完全一致**；
- 点「＋ 添加参数」，每个参数填 字段名 / 说明 / 可选值 / 必填四样；
- 「工具名」留空自动取英文函数名（中文名没字母，会退化成 `tool1`），想指定就直接填；
- 要回传结果就打开「快捷指令会把结果回传给我」，再用那条工具里的「显示「快捷指令」那边怎么配」——里面有现成步骤和**可一键拷贝的回调 URL / 参数说明**；
- 「试运行这条快捷指令」会带上样例参数真跑一次，用来确认名字对得上（没任何反应 = 名字和 App 里对不上）。

工具只能在工具页的表单里一条条加（快捷指令名 / 说明 / 参数行 / 工具名 / 回传开关）—— 界面里没有 JSON 导入，也没有把工具导出成 JSON 的功能；要批量准备工具，可以让助手用「创建工具」能力自己登记，或者用快捷指令传一段配置 JSON（格式见下）。

### 配置文件里的样子

下面这段是配置 JSON 里 `tools` 字段的格式（`tools` 是个数组，这里是其中一条）：

```json
[
  {
    "name": "navigate_home",
    "shortcutName": "导航回家",
    "description": "用地图导航到某个地点",
    "returns": true,
    "params": [
      { "name": "destination", "description": "目的地名称" },
      {
        "name": "mode",
        "description": "出行方式",
        "enum": ["driving", "walking", "transit"],
        "required": false,
        "default": "driving"
      }
    ]
  }
]
```

- `shortcutName`：快捷指令名，要和「快捷指令」App 里**完全一致**（工具页里手输，或粘「快捷指令」里拷来的名字）。
- `params`：参数**数组**，每项一个对象：`name`（字段名）、`description`（说明），可选 `type` / `required` / `enum` / `default`。想省事也可以用 `paramsHint: "destination=目的地名称"` 这种一行一个 `字段名=说明` 的文本写法（结构化 `params` 优先）。
- `type` 支持 `string | number | integer | boolean`；参数**默认全部必填**（快捷指令里「获取词典值」少了键会取不到）。
- `returns: true`：这个快捷指令末尾配了回调 URL，会把结果传回来（见下）。
- `parameters`：优先级最高，直接给一份完整的 JSON schema（自己精细控制时用）。

`name` 不填就按快捷指令名自动生成（中文名里没字母，会退化成 `tool1`）。手写时请用上面这些字段名：以前那套 JSON 导入解析器能认的别名（`shortcut` / `快捷指令` / 参数映射写法）已随解析器一起移除。

**调用（智能体 → 快捷指令）**：`shortcuts://run-shortcut?name=<名>&input=text&text=<JSON>`

- 快捷指令里接参数：「接收输入」（文本）→「从输入获取词典」→ 每个参数一个「获取词典值」。
- 没有参数的工具不传输入。

**回传（快捷指令 → 智能体，可选）**：在快捷指令**末尾加三个动作**

1. 「URL 编码」：输入 = 要回传的内容
2. 「文本」：写 `scripting://run/智能体?tool=<快捷指令名>&callId=`，紧接着从输入词典取到的 `callId`（URL 编码），再写 `&result=` 和 URL 编码后的结果（中间不要有空格或换行）——`callId` 不能省略
3. 「打开 URL」：输入取上一步的文本

并把工具配置里的 `returns` 打开。之后快捷指令的结果回到对话里时会做两件事：

1. 回填到那条工具步骤上（过程卡片从「等回传」变成「已回传」+ 真实结果）；
2. **当成一条隐藏输入，让智能体自动接着回答** —— 它只进上下文，不会作为消息出现在聊天里（过程卡片上标「已回传」）；所以触发工具的那一轮不会干等，也不会卡住界面。

- 回传是异步的：待回传的记录会落在磁盘上留 10 分钟，App 中途被杀掉也能被回调 URL 拉起来接上。回传到达前模型只看到「已触发，结果稍后到」，它不会编造结果。
- 回传必须带本次输入中附带的 `callId`；它用来精确匹配等待中的调用。`tool` 仅用于展示和诊断，不能替代 `callId`。
- 整条 URL 越短越好（建议 2000 字符以内），结果太长就只回传摘要。
- 没配回调的工具一律按「单向触发」处理：模型只知道已触发，不会编造结果。
- 工具页里那条工具的「拷贝完整说明（含回传）」可以把上面的步骤复制到剪贴板。

## 数据与隐私

- **全部结构化数据都在一个目录里**：`<AppGroup>/Documents/agent/data/`（配置、聊天记录、通知记录、诊断、知识库索引、技能注册表、通知队列与回传待办）。**备份只需拷这一个目录**，里面是「一个键一个文件」：`kv/` 放整体替换的数据，`sessions/` `records/` `runs/` 各一条一个文件，`locks/` 是跨进程锁。聊天图片在 `agent/images/`；技能正文在 `agent/skills/<id>/`。
- **为什么不是 SQLite**：这个运行时的 `SQLite` API 需要 Scripting PRO，没解锁时开库直接抛错，整份数据都读不到（快捷指令那条链路上表现为「明明填了 API Key 还说没填」）。改成文件后不再依赖任何付费能力。
- **为什么不会写坏**：每个文件都是先写 `xxx.json.tmp`、写完再 `rename` 成正式文件。同一卷上的 rename 是原子的，所以进程被杀（快捷指令超时、App 被回收）只会留下一个临时文件，不会留下半截 JSON；下次启动时「诊断 → 清理残留文件」能把这些 `.tmp` 扫掉。
- **API Key 不进这个文件**：各供应商 Key / MCP Token / Git 令牌只存在系统钥匙串，库里存的是空串，换设备解不开，也就不会跟着备份泄露。
- 「从 Git 仓库导入」用的访问令牌也存在钥匙串里，只在你点导入时随请求发给你填的那个仓库域名。
- 老版本的 `agent.sqlite` 会在首次打开时自动导出成文件目录并**删除旧库**（导不出来就原样留着，不删）；更老的 `config.json` / `sessions.json` / `message_records.json` / `diagnostics.json` / `notify_queue.json` / `pending.json` / `kb/*.json` / `skills.json` 同样会在首次打开时灌进去并删除；解析失败的单个文件会原样保留（宁可留着让你手工救，也不丢数据）。
- 挂载的外部文件夹以系统**安全作用域书签**保存（只记住你亲自授权的那一个目录），脚本对它是只读的，不会改动里面的文件；取消挂载只删本地索引。
- 头像照片只存在本机 `<AppGroup>/Documents/agent/avatar.png`（不会上传）。
- 网络请求只发往你自己配置的接口（DeepSeek / 你填的 MCP 服务器）。
- 知识库检索完全在本机完成（关键词 BM25），不联网、不上传任何资料。
- 会话历史默认只保留最近 50 条（可配置），不会无限增长。

```
scripting-ts project "智能体" --check     # 类型检查，应为 0 报错
scripting-ts preview_ui chat/page.tsx      # 预览 UI（任何页面都可以单独预览）
```

改代码时按层找位置：

| 想改什么 | 去哪儿 |
| --- | --- |
| 聊天界面、输入栏、气泡 | `chat/` |
| 记录页展示 | `records/` |

| 设置项、模型供应商表单、诊断页 | `settings/` |

## 已知限制

- **快捷指令工具默认拿不到返回值**（iOS 不提供该能力），参数以 JSON 文本单向传过去；要让模型看到结果，需要按上文协议在该快捷指令末尾加「回调 URL」并打开 `returns`，且整条 URL 不能太长（建议 2000 字符以内）。需要省事的真实返回值请用 MCP 工具。
- MCP 只支持**远程 HTTP 型**，本地 stdio 型（`npx …`）在 iOS 沙箱里无法运行。
- 知识库 PDF 需为**可选中文字**的电子版，扫描件抽不出文本；上传与外部文件夹都只能读文本类文档（txt / md / json / csv / log / 源码 / PDF），图片 OCR 与 docx / xlsx 不支持。
- 外部文件夹的书签只能由你在选文件夹时创建，脚本不能自己新建或删除书签。
- **余额只有部分服务商提供**：余额查询**不在 OpenAI 兼容协议里**（DeepSeek `/user/balance`、OpenRouter `/api/v1/credits`、Moonshot `/v1/users/me/balance` 各写各的），中转站基本查不到；硅基流动的 `/v1/user/info` 端点还在但官方已停止下发余额（金额恒为 0，脚本按「查不到 + 说明原因」处理，不显示误导人的 ¥0）。自动查或点「查询余额」失败都只是页面上留一行提示（自动查不弹窗），不影响聊天。
- **「能力」默认全关**，且文件类能力只在本 App 自己的目录内活动（默认工作区 `Scripting/工作区`）；命令行只放行白名单命令，不支持管道 / 重定向 / 串联。
- 工具栏按钮只能是文字（Scripting 会丢弃 `systemImage`）。
